# War Card Game

## Student Name
Chase McKenna

## App Description
War Card Game will be a simple digital version of the classic two-player card game. Players will be able to play through rounds in which each reveals a card, with the higher card winning the round. The app will keep track of the cards won and announce the game's result when one player collects the full deck.

## Intended Users
This app is intended for people who want to play a quick, familiar card game in a web browser, including students learning to build simple interactive apps with Streamlit.

## Planned Features
- Deal and reveal cards for each round.
- Compare card values and resolve ties with a War round.
- Track each player's cards and announce the winner.
